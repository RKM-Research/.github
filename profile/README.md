# RKM Research

**Software research & development**

RKM Research is an independent software research and development organisation based in the United Kingdom.

Our work focuses on developing practical software tools, exploring new technologies, and turning technical ideas into useful products.

Areas of interest include:

* Software development tools
* Data integration, metadata and analytics
* Language and runtime interoperability
* Developer productivity and automation
* Embedded systems and emerging technologies

Selected projects and open-source work will be published here as they become ready for public release.
